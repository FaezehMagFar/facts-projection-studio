# Third-party projects

FACTS Projection Studio is a launcher around independent upstream projects. The
upstream projects are not vendored into this distribution folder and retain
their own copyrights and licenses.

- FACTS model branch used by the installer:
  https://github.com/pkjr002/facts/tree/demo/ssisls
- FACTS upstream project:
  https://github.com/radical-collaboration/facts
- Interactive results dashboard:
  https://github.com/Ttheegela/facts.plotting.dashboard
- SSiSLS installation/course materials:
  https://github.com/SSiSLS/kumar
- FACTS model-description paper:
  https://doi.org/10.5194/gmd-16-7461-2023
- Esri World Topographic Map used by the location preview:
  https://www.arcgis.com/home/item.html?id=30e5fe3149c34df1ba922e6f5bbf808f
- Leaflet interactive map library:
  https://leafletjs.com/

Review each upstream repository's license before redistributing upstream source,
container images, or module datasets. This package downloads them from their
original locations rather than copying them into the package.
